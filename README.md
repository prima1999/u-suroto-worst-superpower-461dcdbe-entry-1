Entry for make.fun's ["Worst Superpower" bounty](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe): invent the most useless superpower in one line of at most 140 characters.

## The entry

> I can read minds, but only the minds of people thinking about me, and every single one of them is just thinking, 'wait, who is that guy?'

Mind-reading that only ever hears strangers wondering who you are: a power whose only use is confirming that nobody knows you. The program keeps ten candidate one-liners and writes the strongest — genuinely useless, funny to picture, unexpected, tight, and clear on one read — to `/output/entry.txt`.

## Run it

Requires Node 22 or later. No dependencies, no network.

```sh
node main.ts
```

It writes a single line (137 characters) to `/output/entry.txt`.
